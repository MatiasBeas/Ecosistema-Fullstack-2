## 📌 01 · SOBRE EL PROYECTO

Este ecosistema reúne los distintos componentes de desarrollo de **Sonido Vivo**, organizados en proyectos de Frontend y Backend.

El objetivo es mantener una estructura ordenada y centralizada que permita acceder fácilmente a cada repositorio y visualizar el avance del desarrollo.

## 🏗️ 02 · ESTRUCTURA DEL ECOSISTEMA

Los repositorios se encuentran organizados en las siguientes áreas:

### 🎨 FRONTEND

| Repositorio | Descripción |
|---|---|
| [Proyecto-Sonido-Vivo](https://github.com/MatiasBeas-SonidoVivo/Proyecto-Sonido-Vivo.git) | Aplicación Frontend desarrollada sin React. |
| [ProyectoSonidoVivo-React](https://github.com/MatiasBeas-SonidoVivo/ProyectoSonidoVivo-React) | Aplicación Frontend desarrollada con React. |

### ⚙️ BACKEND

| Repositorio | Descripción |
|---|---|
| [BackendProyectoSonidoVivo-Productos](https://github.com/MatiasBeas-SonidoVivo/BackendProyectoSonidoVivo-Productos) | Microservicio encargado de la gestión de productos. |

*Los próximos microservicios se incorporarán a medida que avance el desarrollo.*
